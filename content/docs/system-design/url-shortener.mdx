# 问题

短链系统怎么设计读写和发号？

# 30秒回答

写路径生成全局唯一短码，存短码到长链。读路径要极快，缓存热点短码，未命中再查库。短码用号段或哈希截断加冲突检测，不要在跳转请求里做重计算。

# 深入理解

先问 QPS、过期、统计和防刷。301/302 看要不要统计点击。发号可以预分配号段，应用内自增后编码成 base62。读多写少，短码作缓存 key。自定义短码要做保留字和审核。

容量粗算：短码、长链、过期时间、计数。热点活动链单独加本地缓存。

# 面试追问

## 哈希冲突怎么办？

截断后查重，冲突就换盐或加序号。号段方案天然避开随机冲突。

## 跳转为什么放缓存？

跳转是绝对读多。只缓存热点，冷门回源，避免缓存被扫库打满。
