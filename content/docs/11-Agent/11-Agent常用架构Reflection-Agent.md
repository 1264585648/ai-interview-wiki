# ✅Agent常用架构：Reflection Agent

前面介绍提示词工程的时候也提过这种反思的思路。

它是一种让模型**自我批判、自我修正**的策略。其核心思想是：**让大语言模型（LLM）在完成任务后，对其自身的行为或输出进行批判性反思，并基于反思结果进行改进**。

虽然我们有了ReAct或者Plan and Execute等agent架构，但是人们发现还是很多时候在Agent执行后存在一定的问题，因为模型幻觉天然存在，于是有人提出给agent引入反思机制。

LangChain还把Reflection分成了多种不同的实现，包括Basic Reflection、Reflexion以及LATS（[https://www.blog.langchain.com/reflection-agents/](https://www.blog.langchain.com/reflection-agents/) ） 。

如以下，使我们用python实现的一个具有反思能力的智能体:

让智能体写一段关于“气候变化对农业的影响”的简短文章，并通过自我反思迭代改进其内容（如逻辑性、完整性、语言流畅度）。

```
# reflection_agent.py
from typing import TypedDict, List
from langchain_openai import ChatOpenAI
from langchain_core.prompts import ChatPromptTemplate
from langgraph.graph import StateGraph, END

OPENAI_API_KEY = "sk-8ef405c4686e456e91f6698272253126"
OPENAI_API_BASE = "https://dashscope.aliyuncs.com/compatible-mode/v1"

# 定义状态结构
class AgentState(TypedDict):
    draft: str                      # 当前草稿
    feedback: str                   # 反思反馈
    revision_number: int            # 当前修订次数
    max_revisions: int              # 最大修订次数

# 初始化 LLM（使用 GPT-4o 或你偏好的模型）
llm = ChatOpenAI(
    model="deepseek-v3",
    api_key=OPENAI_API_KEY,
    base_url=OPENAI_API_BASE,
    temperature=0.7,
)


# === 节点 1：起草初稿 ===
draft_prompt = ChatPromptTemplate.from_messages([
    ("system", "你是一位专业的科普作家。请撰写一篇关于“气候变化对农业的影响”的简短文章（约200字）。"),
    ("user", "请开始写作。")
])

def draft_writer(state: AgentState) -> dict:
    response = llm.invoke(draft_prompt.format())
    return {"draft": response.content}

# === 节点 2：反思（提供改进建议）===
reflection_prompt = ChatPromptTemplate.from_messages([
    ("system", "你是一位严谨的编辑。请对以下文章草稿进行批判性反思，指出其在逻辑、事实准确性、完整性或语言表达方面的不足，并给出具体改进建议。"),
    ("user", "草稿：\n{draft}")
])

def reflector(state: AgentState) -> dict:
    response = llm.invoke(reflection_prompt.format(draft=state["draft"]))
    return {"feedback": response.content}

# === 节点 3：修订草稿 ===
revision_prompt = ChatPromptTemplate.from_messages([
    ("system", "你是一位专业作家。请根据以下编辑反馈，修改你的文章草稿。保留原意，但提升质量。"),
    ("user", "原草稿：\n{draft}\n\n编辑反馈：\n{feedback}\n\n请输出修订后的文章。")
])

def reviser(state: AgentState) -> dict:
    response = llm.invoke(
        revision_prompt.format(draft=state["draft"], feedback=state["feedback"])
    )
    return {
        "draft": response.content,
        "revision_number": state["revision_number"] + 1
    }

# === 条件判断：是否继续反思？===
def should_continue(state: AgentState) -> str:
    if state["revision_number"] < state["max_revisions"]:
        return "reflect"
    else:
        return END

# === 构建图 ===
builder = StateGraph(AgentState)

# 添加节点
builder.add_node("draft", draft_writer)
builder.add_node("reflect", reflector)
builder.add_node("revise", reviser)

# 设置入口
builder.set_entry_point("draft")

# 定义边
builder.add_edge("draft", "reflect")
builder.add_edge("reflect", "revise")

# 条件循环：从 revise 回到 reflect，或结束
builder.add_conditional_edges(
    "revise",
    should_continue,
    {"reflect": "reflect", END: END}
)

# 编译图
graph = builder.compile()

# === 运行智能体 ===
if __name__ == "__main__":
    initial_state = {
        "draft": "",
        "feedback": "",
        "revision_number": 0,
        "max_revisions": 2  # 最多修订2次（即总共3个版本：初稿 + 2次修订）
    }

    result = graph.invoke(initial_state)

    print("\n" + "="*50)
    print("最终文章：")
    print(result["draft"])
    print("="*50)
```

气候变化正在通过非线性路径重构全球农业生产系统。根据IPCC第六次评估报告（WGII第5章），1970-2020年间全球地表温度以0.2°C/十年的速率上升，这种变化通过热力学、水文学和生态学的三重耦合机制影响农业，并触发级联式灾害链。本文基于最新实证数据，构建"胁迫-响应-适应"分析框架，揭示不同尺度下的影响差异及转型路径。

### 一、气候变化的直接胁迫机制
1. **热力学效应**
