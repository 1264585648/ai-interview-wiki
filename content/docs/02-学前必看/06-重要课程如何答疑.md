# ✅【重要】课程如何答疑？

有3种方式。（另外需要注意，不要在小鹅通里面的视频下方问问题，默认是不回复的哦~有问题可以以下3种方式提问。）

1、在项目交流群中问。

大家可以加一下项目交流群：

有问题可以在群里面和大家交流，也可以at我问。我会定期回复。（也可以在群里直接加我V，直接问我也行）

**因为群里面消息比较多，所以如果我没有及时回复你，请到知识星球中发帖，我都会回复**

2、在知识星球中问

大家可以加一下这个**项目课专属，免费的知识星球**，作为日常的交流，大家可以把自己遇到的问题在这里发布，会有人答疑，也可以从星球中搜索相关问题，后续如果有一些面试题也可以发里面。

[https://t.zsxq.com/QTLEU](https://t.zsxq.com/QTLEU) （链接只能微信手机端访问，加入后，百度搜索"知识星球"（或下载知识星球 APP），登录账号查看）

或者也可以到交流群的群公告中加入星球。

3、直播间问

我每周末都会直播，在我的抖音号@程序员Hollis 上面，可以连麦直接问。
