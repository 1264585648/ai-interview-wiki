# ✅【重要】如何查看视频

我们的视频是在小鹅通上面学习的，大家可以通过下单时收到的短信，申请小鹅通权限，开通后，可以通过小鹅通小程序进行学习。

需要注意一下，你的微信绑定手机号需要和开通手机号一致，否则需要单独登录一下。

![2bebfdab530e7799208ec2b4623ad563.jpg](assets/f5284ab98966.jpg)

电脑端也可以通过[https://study.xiaoe-tech.com/#/wx](https://study.xiaoe-tech.com/#/wx) 进入，用你的微信扫码或手机号登录即可。
