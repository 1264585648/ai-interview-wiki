# ✅价格和时间的分数归一化和加权分计算

系统帮用户规划行程时，会生成很多种组合方案（不同航班 × 不同酒店 × 不同返程）。

每个组合有两个关键指标：

- **总价**（元）—— 越低越好
- **总交通时间**（分钟）—— 越短越好

问题来了：一个是"元"，一个是"分钟"，单位不同，没法直接比较和加权。

**解决办法**：把这两个指标都转换成 0~100 的"打分"，100 分最好，0 分最差。这样就能和"偏好分"一起加权算综合排名了。

**打个比方**：三个同学考试，A 考了 60 分，B 考了 100 分，C 考了 80 分。

如果要把他们的成绩映射到 0~100 的"相对排名分"：

- B 是最高分 → 100 分
- A 是最低分 → 0 分
- C 在中间 → 按比例算出 50 分

这就是归一化——把一组的最高值设为满分（或零分，取决于越大越好还是越小越好），最低值设为零分（或满分），中间的按比例分配。

具体怎么做？

第一步：找出最高和最低

从所有组合中，分别找出：

- 价格最高 / 最低
- 时间最长 / 最短

第二步：逐个打分

对于每个组合，套用这个公式：

```text
比例 = (当前值 - 最低值) / (最高值 - 最低值)
```

这个比例算出来一定在 0~1 之间：

- 当前值 = 最低值 → 比例 = 0
- 当前值 = 最高值 → 比例 = 1

第三步：反转（因为越小越好）

价格和时间都是越低越好，所以要反转：

```text
最终比例 = 1 - 比例
```

这样：

- 最便宜的（比例=0）→ 反转后 = 1 → 100 分 ✅
- 最贵的（比例=1）→ 反转后 = 0 → 0 分 ✅

第四步：放大到百分制

```text
得分 = 最终比例 × 100
```

实际例子

假设有 3 个行程组合：

| 组合 | 总价(元) | 总时间(分钟) |
| --- | --- | --- |
| A | 1200 | 300 |
| B | 2000 | 240 |
| C | 800 | 360 |

先算价格分

价格最低 = 800（组合 C），价格最高 = 2000（组合 B），差值 = 1200

| 组合 | 计算 (price - 800) / 1200 | 比例 | 反转 1 - 比例 | 价格分 |
| --- | --- | --- | --- | --- |
| A | (1200-800) / 1200 = 0.33 | 0.33 | 0.67 | **67** |
| B | (2000-800) / 1200 = 1.00 | 1.00 | 0.00 | **0** |
| C | (800-800) / 1200 = 0.00 | 0.00 | 1.00 | **100** |

解读：C 最便宜所以 100 分，B 最贵所以 0 分，A 在中间得了 67 分。

再算时间分

时间最短 = 240（组合 B），时间最长 = 360（组合 C），差值 = 120

| 组合 | 计算 (time - 240) / 120 | 比例 | 反转 1 - 比例 | 时间分 |
| --- | --- | --- | --- | --- |
| A | (300-240) / 120 = 0.50 | 0.50 | 0.50 | **50** |
| B | (240-240) / 120 = 0.00 | 0.00 | 1.00 | **100** |
| C | (360-240) / 120 = 1.00 | 1.00 | 0.00 | **0** |

解读：B 最快所以 100 分，C 最慢所以 0 分，A 在中间得了 50 分。

算完之后干嘛？

现在每个组合都有了统一的 0~100 分：

| 组合 | 价格分 | 时间分 | 偏好分 |
| --- | --- | --- | --- |
| A | 67 | 50 | ... |
| B | 0 | 100 | ... |
| C | 100 | 0 | ... |

用户可以设权重，比如"时间:价格:偏好 = 3:2:5"：

```text
综合分 = 时间分 × 0.3 + 价格分 × 0.2 + 偏好分 × 0.5
```

代码里的默认权重是 **偏好 50% > 时间 30% > 价格 20%** （因为差旅场景公司买单，用户体验优先于省钱）！

这里除了上面三个评分以外，为了减少review出现很多问题，我们后来又加了一个体验分进去。但是整体的方案没啥变化。

但是，如果你站在公司的角度，毕竟我们是给公司开发系统，那么你就可以适当的调高这个价格的权重。还可以做的更好一点，我可以根据用户的情况，去给他调整不同的权重。

最终按综合分排序，挑出四个代表方案推荐给用户：

| 标签 | 怎么选 |
| --- | --- |
| 综合最佳 | 综合分最高的 |
| 时间最短 | 总时间最短的 |
| 价格最低 | 总价最低的 |
| 最符合偏好 | 偏好分最高的 |
