# ✅出差目的地实时联网查询工具定义及开发

差旅是一件强依赖「当下外部世界状态」的事。用户问的往往不是知识库里静态的东西，而是：

- 「我后天去杭州，要带伞吗？」——需要**实时天气**
- 「这周去北京，有没有大型活动导致酒店紧张 / 交通管制？」——需要**目的地资讯**
- 「下个月去日本出差，我这本护照要不要签证？」——需要**签证政策**

这三类信息的共同点是：**训练语料里没有、RAG 知识库里也不该塞**（会过期），必须在对话发生的那一刻去联网拉取。所以 gogo-agent 专门有一套「目的地实时联网查询」工具族。

新闻资讯的工具接入

query_destination_news：目的地资讯查询，我们使用newsdata（[https://newsdata.io/](https://newsdata.io/) ）提供的api做查询。

```text
@Tool(name = "query_destination_news",
      description = "联网查询出差目的地的最新资讯，辅助出行规划与风险评估。\n"
              + "可查询主题（topic 参数）：\n"
              + "- traffic：交通管制、道路封闭、限行限号\n"
              + "- event：重大展会、会议、赛事、演艺\n"
              + "- safety：治安状况、示威扰乱、突发事件\n"
              + "- flight：航班延误、机场动态、天气取消\n"
              + "- hotel：酒店旺季预定紧张期、封闭消息\n"
              + "- policy：入境新规、签证政策变动\n"
              + "- general：综合资讯（默认）\n")
public String queryDestinationNews(
        @ToolParam(name = "city", description = "目标城市，如 北京、上海、杭州、深圳") String city,
        @ToolParam(name = "topic",
                   description = "关注主题：traffic / event / safety / flight / hotel / policy / general，可选",
                   required = false) String topic) {
```

它的第一段是这一族工具「优雅降级」哲学最典型的体现——**Key 没配就降级，而不是报错**：

```text
if (newsApiKey == null || newsApiKey.isBlank()) {
    JSONObject placeholder = new JSONObject();
    placeholder.put("city", city);
    placeholder.put("available", false);
    placeholder.put("note",
            "新闻查询功能需配置 app.news-api-key（免费注册：https://newsdata.io），当前未启用。"
                    + "如需获取目的地资讯，建议引导用户自行查阅当地官方网站或新闻媒体。");
    return JSON.toJSONString(placeholder);
}
```

available=false 这个标志位又是「用返回值驱动大模型行为」的例子：大模型看到 available:false 就知道这个能力当前不可用，会转而给用户一个替代建议，而不是硬编一条假新闻。

真正联网的部分用 WebClient 的 uriBuilder 拼查询串，把「城市 + 主题」组成一个查询词（如 "北京 交通"），限定中文、最多 5 条

```text
String query = city + (topic != null && !topic.isBlank() ? " " + topic : "");
String responseBody = webClient.get()
        .uri(uriBuilder -> uriBuilder
                .scheme("https").host("newsdata.io").path("/api/1/news")
                .queryParam("apikey", newsApiKey)
                .queryParam("q", query)
                .queryParam("language", "zh")
                .queryParam("size", NEWS_PAGE_SIZE)      // "5"
                .build())
        .retrieve().bodyToMono(String.class)
        .timeout(Duration.ofSeconds(NEWS_REQUEST_TIMEOUT_SECONDS))   // 10s
        .block();
```

返回时同样做投影，只留 title / description / pubDate / source 四个字段，空结果给友好提示，异常仍走 available=false + error 的兜底。整个方法从头到尾没有一条会把异常抛给框架的路径。
