# ✅用户联系信息工具定义及开发

差旅 Agent 下单时需要姓名、手机号、身份证号、邮箱。在做行程发起（提交审批的时候）时也需要可以推断用户的出发地。这些信息不能每次都让用户填写，一般来说个人在企业中是有维护过这些信息的。但是我们也需要支持以下几个能力：

**预订接口对字段要求不同**。途牛机票要中文姓名 + 身份证 + 手机号 + 性别（五字段全齐才能下单），酒店要姓名拼音 + 邮箱（两字段），火车票要姓名 + 证件号。Agent 不能一上来就一次性问七八个问题把用户吓跑，而是应该"先看已有档案缺什么，只追问当前下单类型真正缺的那几个"。

**能记住"用户刚才告诉过我的信息"**。如果不持久化，LLM 在下一轮对话又会问用户"你叫什么名字"。持久化到 DB + 会话缓存，任何时刻 LLM 查一次就能拿到已有信息，不再重复问。

**用户更正了信息需要立刻生效**。用户说"手机号填错了，应该是 138xxxx"，Agent 调 update 后，如果缓存不失效，同一个对话里后续下单依然拿旧手机号。

我们把关于用户的联系信息相关的获取和更新，封装到UserInfoReadTools、UserInfoWriteTools

| 工具名 | 语义 | 完整性影响 |
| --- | --- | --- |
| query_user_contact_info | 读取用户联系/乘机人档案 | 只读，回源后缓存 |
| update_user_contact_info | 更新任意子集字段 | 写入 DB + 失效缓存 |
| query_user_base_location | 读取常驻城市 | 只读，缓存不失效 |
| update_user_base_location | 更新常驻城市 | 写入 DB + 失效缓存 |

query_user_base_location

这个工具在行程规划是就需要。其他两个工具只有在预定时才需要。

```text
@Tool(name = "query_user_base_location",
      description = "查询用户常驻/办公城市，用于在用户未提供出发地时推断出发城市")
public String queryUserBaseLocation(AgentSessionContext sessionCtx) {
    String cached = sessionCtx.getUserBaseLocation();
    if (cached != null) return cached;

    Optional<UserProfile> profile = userProfileRepository.findByUserId(sessionCtx.getUserId());
    String result;
    if (profile.isPresent()) {
        String baseCity = profile.get().getBaseCity();
        if (baseCity != null && !baseCity.isBlank()) {
            result = JSON.toJSONString(Map.of("userId", userId, "baseCity", baseCity));
        } else {
            // baseCity 为空 → 提示 LLM 追问
            result = JSON.toJSONString(Map.of("userId", userId, "baseCity", "",
                    "message", "未查询到用户的常驻城市，请向用户询问出发城市"));
        }
    } else {
        result = JSON.toJSONString(Map.of("userId", userId, "baseCity", "",
                "message", "未找到用户档案，请向用户询问出发城市"));
    }
    sessionCtx.setUserBaseLocation(result);   // 缓存 — 无对应 update 工具，故永不失效
    return result;
}
```

这里用到了缓存，在同一个对话中避免重复查询数据库：

query_user_contact_info

```text
@Tool(name = "query_user_contact_info",
      description = "查询用户的联系信息和乘机人信息，包括姓名拼音、邮箱、中文姓名、证件类型、证件号码、手机号、性别。"
                  + "用于酒店/机票预订时自动填充联系人和乘客信息。"
                  + "若档案中缺少相关信息，返回提示让 Agent 向用户追问。")
public String queryUserContactInfo(AgentSessionContext sessionCtx) {
    // ① 会话级缓存命中则直接返回（同一对话内多次下单不必反复查 DB）
    String cached = sessionCtx.getUserContactInfo();
    if (cached != null) {
        return cached;
    }

    String userId = sessionCtx.getUserId();
    Optional<UserProfile> optProfile = userProfileRepository.findByUserId(userId);
    Map<String, Object> result = new HashMap<>();
    result.put("userId", userId);

    if (optProfile.isPresent()) {
        UserProfile profile = optProfile.get();
        // ② 逐字段判空
        boolean hasNamePinyin  = profile.getNamePinyin()  != null && !profile.getNamePinyin().isBlank();
        boolean hasEmail       = profile.getEmail()       != null && !profile.getEmail().isBlank();
        boolean hasChineseName = profile.getChineseName() != null && !profile.getChineseName().isBlank();
        boolean hasIdType      = profile.getIdType()      != null;
        boolean hasIdNumber    = profile.getIdNumber()    != null && !profile.getIdNumber().isBlank();
        boolean hasPhone       = profile.getPhone()       != null && !profile.getPhone().isBlank();
        boolean hasGender      = profile.getGender()      != null && !profile.getGender().isBlank();

        // ③ 酒店预订需要的字段：拼音 + 邮箱
        if (hasNamePinyin) {
            String[] parts = profile.getNamePinyin().trim().split("\\s+", 2);
            result.put("lastName",   parts[0]);
            result.put("firstName",  parts.length > 1 ? parts[1] : "");
            result.put("namePinyin", profile.getNamePinyin());
        }
        if (hasEmail)       result.put("email",       profile.getEmail());

        // ④ 机票预订需要的字段：中文姓名 + 证件 + 手机 + 性别
        if (hasChineseName) result.put("chineseName", profile.getChineseName());
        if (hasIdType) {
            result.put("idType",      profile.getIdType());
            result.put("idTypeLabel", ID_TYPE_LABEL.getOrDefault(profile.getIdType(), "未知"));
        }
        if (hasIdNumber) result.put("idNumber", profile.getIdNumber());
        if (hasPhone)    result.put("phone",    profile.getPhone());
        if (hasGender)   result.put("gender",   profile.getGender());

        // ⑤ 完整性标记——LLM 读这两个布尔值决定是否追问
        boolean hotelComplete  = hasNamePinyin && hasEmail;
        boolean flightComplete = hasChineseName && hasIdType && hasIdNumber && hasPhone && hasGender;
        result.put("hotelComplete",  hotelComplete);
        result.put("flightComplete", flightComplete);
        result.put("complete",       hotelComplete && flightComplete);

        // ⑥ 追问引导语：只列缺失字段，LLM 原样复述给用户
        if (!hotelComplete || !flightComplete) {
            StringBuilder hint = new StringBuilder("用户档案中缺少以下信息，请向用户追问：");
            if (!hasNamePinyin)  hint.append("姓名拼音（如 ZHANG SAN）；");
            if (!hasEmail)       hint.append("邮箱地址；");
            if (!hasChineseName) hint.append("中文姓名（如 张三）；");
            if (!hasIdType)      hint.append("证件类型（...）；");
            if (!hasIdNumber)    hint.append("证件号码；");
            if (!hasPhone)       hint.append("手机号；");
            if (!hasGender)      hint.append("性别（男/女）；");
            result.put("message", hint.toString());
        }
    } else {
        // 档案完全不存在，返回全量追问提示
        result.put("complete", false);
        result.put("hotelComplete", false);
        result.put("flightComplete", false);
        result.put("message", "未找到用户档案，请向用户询问姓名拼音、邮箱、中文姓名、证件类型、证件号码、手机号、性别");
    }

    String json = JSON.toJSONString(result);
    sessionCtx.setUserContactInfo(json);       // ⑦ 写缓存
    return json;
}
```

七步走读：① 缓存短路 → ② 逐字段 null 检查 → ③ 拆解酒店需要的子集 → ④ 拆解机票需要的子集 → ⑤ 计算两个 complete 标记 → ⑥ 动态拼装"只追问缺失字段"的引导语 → ⑦ 写入 session 缓存。

update_user_contact_info

```text
@Tool(name = "update_user_contact_info",
      description = "更新用户的联系信息和乘机人信息。支持以下字段：..."
                  + "当用户主动提供或修正了以上任意信息时调用，至少提供一个字段。")
public String updateUserContactInfo(
        AgentSessionContext sessionCtx,
        @ToolParam(name = "name_pinyin",  required = false) String namePinyin,
        @ToolParam(name = "email",        required = false) String email,
        @ToolParam(name = "chinese_name", required = false) String chineseName,
        @ToolParam(name = "id_type",      required = false) Integer idType,
        @ToolParam(name = "id_number",    required = false) String idNumber,
        @ToolParam(name = "phone",        required = false) String phone,
        @ToolParam(name = "gender",       required = false) String gender) {

    // ① 至少要有一个字段（空调用检测）
    if (!hasNamePinyin && !hasEmail && !hasChineseName && !hasIdType
            && !hasIdNumber && !hasPhone && !hasGender) {
        return JSON.toJSONString(Map.of("success", false,
                "message", "至少需要提供其中一个字段..."));
    }

    // ② 查出现有 profile（如果不存在直接失败——不自动创建）
    Optional<UserProfile> optProfile = userProfileRepository.findByUserId(userId);
    if (optProfile.isEmpty()) {
        return JSON.toJSONString(Map.of("success", false,
                "message", "未找到用户档案，无法更新"));
    }

    UserProfile profile = optProfile.get();
    List<String> updatedFields = new ArrayList<>();

    // ③ 部分写：只覆盖有值的字段（PATCH 语义）
    if (hasNamePinyin) {
        profile.setNamePinyin(namePinyin.trim().toUpperCase());   // 强制大写
        updatedFields.add("name_pinyin");
    }
    if (hasEmail)       { profile.setEmail(email.trim());          updatedFields.add("email"); }
    if (hasChineseName) { profile.setChineseName(chineseName.trim()); updatedFields.add("chinese_name"); }
    if (hasIdType)      { profile.setIdType(idType);              updatedFields.add("id_type"); }
    if (hasIdNumber)    { profile.setIdNumber(idNumber.trim());   updatedFields.add("id_number"); }
    if (hasPhone)       { profile.setPhone(phone.trim());         updatedFields.add("phone"); }
    if (hasGender) {
        String normalized = normalizeGender(gender.trim());       // ④ 支持中文"男"→"M"
        profile.setGender(normalized);
        updatedFields.add("gender");
    }

    userProfileRepository.save(profile);                          // ⑤ upsert 落库
    sessionCtx.invalidateUserContactInfo();                       // ⑥ 失效缓存——关键！

    // ⑦ 返回成功 + 回显更新后的字段值，LLM 可以向用户确认
    Map<String, Object> result = new HashMap<>();
    result.put("success", true);
    result.put("userId", userId);
    result.put("updatedFields", updatedFields);
    ...
    return JSON.toJSONString(result);
}
```

**normalizeGender** 是一个三行容错：

```text
private String normalizeGender(String input) {
    String upper = input.toUpperCase();
    if ("M".equals(upper) || "男".equals(input) || "MALE".equals(upper)) return "M";
    if ("F".equals(upper) || "女".equals(input) || "FEMALE".equals(upper)) return "F";
    return upper;  // 原样返回，不抛异常
}
```

**缓存失效的时序保证**：invalidateUserContactInfo() 是**写 DB 成功后才调用**的。如果 DB 写失败（例如异常），方法直接 throw，不会走到 invalidate，缓存里还是老的有效值——符合"缓存不能比 DB 新"的基本原则。

update_user_base_location

```text
/**
 * 更新用户常驻/办公城市。用户告知常驻城市变化（搬家、更换工作城市）时调用。
 */
@Tool(name = "update_user_base_location",
      description = "更新用户的常驻/办公城市。当用户告知常驻城市发生变化（如搬家、更换工作城市）时调用，后续推断出发地将使用新城市。")
public String updateUserBaseLocation(
        AgentSessionContext sessionCtx,
        @ToolParam(name = "base_city", description = "常驻城市名，如 北京、深圳") String baseCity) {

    String userId = sessionCtx.getUserId();
    logger.info("[TOOL][update_user_base_location] userId={}, baseCity={}", userId, baseCity);

    if (baseCity == null || baseCity.isBlank()) {
        return JSON.toJSONString(Map.of("success", false, "message", "base_city 不能为空，请向用户确认常驻城市"));
    }
    String city = baseCity.trim();
    if (city.length() > 30) {
        return JSON.toJSONString(Map.of("success", false, "message", "base_city 过长，请向用户确认常驻城市名称"));
    }

    // 档案不存在时自动创建，与 update_user_contact_info 行为一致
    Optional<UserProfile> optProfile = userProfileRepository.findByUserId(userId);
    boolean created = optProfile.isEmpty();
    UserProfile profile = optProfile.orElseGet(() -> new UserProfile(userId, null));
    profile.setBaseCity(city);
    userProfileRepository.save(profile);
    // 常驻城市已变更，失效会话内缓存，下次查询回源数据库
    sessionCtx.invalidateUserBaseLocation();

    Map<String, Object> result = new HashMap<>();
    result.put("success", true);
    result.put("userId", userId);
    result.put("baseCity", city);
    if (created) {
        result.put("created", true);
    }
    String json = JSON.toJSONString(result);
    logger.info("[TOOL][update_user_base_location] result={}", json);
    return json;
}
```
