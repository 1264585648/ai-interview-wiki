# ✅通过换模型解决忠诚度低的问题

我们的问题：智界R7那个行车记录仪拍的视频，平时怎么调出来看啊？想导出来又该咋整？

在评测时发现忠诚度比较低，才0.6都不到，于是我们开始分析回答的结果和参考资料之间的关系。

以下是一次回答结果：

````
要查看智界R7行车记录仪拍摄的视频，以及导出数据，具体操作如下：

---

### ✅ 一、如何查看行车记录仪视频？

1. **打开行车记录仪应用**  
   - 在中控屏上，点击状态栏中的 **行车记录仪图标**（或通过“应用与服务 > 应用中心 > 行车记录仪”进入）。
   - 图标状态说明：
     - 🔴 表示正在录制且录音中；
     - ⬜ 表示已停止录制；
     - ⚠️ 表示存在故障。

2. **进入主界面查看内容**  
   - 进入应用后，可在首页查看以下三类数据：
     - **抓拍录像**：碰撞触发或手动触发的视频，保存在“抓拍录像”文件夹，不会被自动覆盖。
     - **循环录像**：车辆启动后自动录制的连续视频，按时间顺序存储于“循环录像”文件夹，旧视频会被新视频覆盖。
     - **拍照**：拍摄的图片或视频回放截图。

3. **查看视频详情**  
   - 点击对应视频缩略图可播放。
   - 可使用“实时画面”按钮查看当前摄像头画面。
   - 在编辑模式下，可对视频进行删除、锁定（防止被覆盖）、导出等操作。

---

### ✅ 二、如何将视频导出？

#### 方法一：导出到手机（推荐用于快速分享）

1. 进入行车记录仪应用 → 切换至 **编辑模式**。
2. 选择需要导出的视频或照片。
3. 点击“发送至手机”选项，系统会通过蓝牙或Wi-Fi将文件传输至绑定的手机。
4. 手机接收后可在相册或文件管理中查看。

> 💡 提示：确保手机已与车辆完成权限授权，并处于同一网络环境。

#### 方法二：直接从Micro SD卡导出（适用于批量导出或备份）

1. 打开副驾隐私储物箱，取出 Micro SD 卡。
2. 将 Micro SD 卡插入电脑的读卡器，或使用手机OTG功能读取。
3. 文件路径结构如下：
   ```
   /DCIM/
     └── 100R7/
         ├── CrashRecord/       ← 抓拍录像
         ├── LoopRecord/        ← 循环录像
         └── Photo/             ← 拍照图片
   ```
4. 直接复制所需视频文件到电脑或移动设备保存。

> ⚠️ 注意事项：
> - 必须使用 **32GB~128GB 的正版 Micro SD 卡**，不支持 NTFS 格式。
> - 插拔存储卡或意外断电可能导致视频丢失，请避免在录制过程中操作。
> - 不要在该卡中存放其他文件，以免造成数据损坏或丢失。

---

### ✅ 三、重要提醒

- **登录账号**：只有登录用户才能查看自己产生的数据；未登录时所有用户均可查看。
- **数据安全**：已录制的视频仅存储在副驾隐私储物箱内的 Micro SD 卡中，请妥善保管。
- **锁定视频**：若想保留某段重要视频不被覆盖，可在编辑模式中“锁定”该视频。

---

如需恢复出厂设置或清除全部数据，可在设置中选择“恢复默认设置并清除数据”，但此操作不可逆，请谨慎使用。
````

RAG 生成环节使用专用强模型

在 ChatApplicationService 中新建了一个 RAG 专用的 StreamingChatModel，与系统中意图识别、查询改写等环节使用的通用模型解耦：

```
private StreamingChatModel ragChatModel;

@PostConstruct
public void init() &#123;
    ragChatModel = OpenAiStreamingChatModel.builder()
            .apiKey(chatModelApiKey)
            .baseUrl(chatModelBaseUrl)
            .modelName("qwen3.6-plus")        // 使用更强的模型
            .temperature(0.2)                 // 低温度，减少随机性
            .topP(0.9)
            .customParameters(Map.of("enable_thinking", false))  // 关闭思维链
            .build();
&#125;
```

在构建 AiServices 时，将 RAG 对话环节的模型从默认注入的 streamingChatModel 替换为 ragChatModel：

```
KnowEngineChatAiService knowEngineChatAiService = AiServices.builder(KnowEngineChatAiService.class)
        .streamingChatModel(ragChatModel)   // 使用 RAG 专用模型
        ...
        .build();
```
