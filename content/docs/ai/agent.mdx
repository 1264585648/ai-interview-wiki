# 问题

一个可用的 Agent 最小架构是什么？

# 30秒回答

模型负责决定下一步，工具负责做事，状态记录已经做过什么，循环直到能给最终答案或超过步数。没有工具边界和停止条件的 Agent 只是会空转的聊天。

# 深入理解

常见循环是观察、推理、行动。工具要有明确输入输出和失败信息。记忆分短期对话和长期资料，长期资料通常还是检索，不是把历史全塞进提示词。

生产里要限制最大步数、可调用工具、超时和权限。规划可以先写步骤，也可以每步动态选工具。不要把所有能力都做成一个万能工具。

# 面试追问

## Agent 和 RAG 的差别？

RAG 主要是检索后一次生成。Agent 会根据中间结果决定要不要再查、再调用、再改计划。

## 怎么防止死循环？

步数上限、重复调用检测、工具失败后换策略，以及要求模型给出结束信号。
