# 问题

Embedding 表示什么，为什么相似问题还能召回失败？

# 30秒回答

Embedding 把文本映射成固定维度向量，用距离近似语义相近。它压缩了信息，对专有名词、否定、数字和最新术语不稳定。召回失败要查切块、模型和 query 是否同一语义空间。

# 深入理解

常用余弦相似度。向量维度不是越高越好，要在召回率和成本之间取舍。同一套模型同时编码问题和文档。中文专有词、代码、表格要单独处理，不能和普通段落混成一个块。

换模型等于重建索引。不要用生成模型的内部状态假装 Embedding。

# 面试追问

## 余弦和欧氏距离怎么选？

多数文本向量已经归一化，余弦更直观。没归一化时欧氏会混进长度。

## 为什么关键词检索还要留？

专有 ID、错误码、精确短语，向量检索经常不如倒排。混合召回更稳。
