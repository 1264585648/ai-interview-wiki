# 问题

MCP 解决什么问题，和直接写 Function Calling 有何不同？

# 30秒回答

MCP 是模型和外部工具、数据源之间的通用协议。工具方实现一次 MCP 服务，多个宿主就能发现工具、读资源和调用。Function Calling 是模型发出调用的格式，MCP 是工具如何被暴露和连接。

# 深入理解

典型能力包括工具、资源和提示模板。宿主负责权限、审批和把 MCP 工具映射成模型可调用的函数。这样不必为每个产品重写一套数据库或文档连接器。

面试里要讲清边界：MCP 不替你做规划，也不保证工具安全。鉴权、超时、最小权限仍在宿主。

# 面试追问

## 为什么不每个工具都手写适配？

手写适配把每个数据源绑死在一个应用里。协议让工具可复用，宿主只做发现和权限。

## MCP 会替代 RAG 吗？

不会。MCP 可以提供“去哪个知识源查”的工具，检索质量仍由文档、切片和召回决定。
